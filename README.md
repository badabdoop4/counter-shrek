# Counter Shrek (Web Edition)
Counter Shrek is a fast paced multiplayer shooter game made in Godot inspired by Counter Strike. You can play Counter Shrek online at https://badabdoop4.github.io/counter-shrek/, or by downloading the desktop version in the releases page.

> [!IMPORTANT]
> Please note that Counter Shrek is still very early in development. If you encounter a serious bug, you can file an issue report above.
